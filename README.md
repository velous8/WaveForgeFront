# Wave Forge — Frontend

## Описание

Клиентская часть приложения для просмотра музыкальных сэмпл-паков, прослушивания аудиопревью и выбора наборов.

## Стек

* React

* JavaScript

* React Router

* CSS

## Установка

```
npm install
npm start
```

Перед запуском настройте подключение к backend API при необходимости.
